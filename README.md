# Рыбалка (How to Fish / Yandex Games)

MVP-копия геймплея **How to Fish** для публикации на **Яндекс Игры** (Yandex Games).
2D top-down, весь мир и UI строятся кодом из примитивов — внешние ассеты не нужны.

Замкнутый цикл: **заброс удочки → клёв → вываживание → выброс рыбы на берег → убийство →
продажа торговцу → покупка оружия/апгрейдов → ловля более ценной рыбы.**

## Как собирается проект (CI)

Unity локально НЕ требуется: WebGL-сборка выполняется на облачных раннерах **GitHub Actions**
путём Docker-образа `unityci/editor` (Unity **6000.0.23f1** + WebGL). Нужен только GitHub-аккаунт.

### Первичная настройка (один раз)

1. Создайте репозиторий на GitHub (Public — бесплатно). Отправьте этот проект:
   ```
   git init
   git add .
   git commit -m "MVP How to Fish"
   git branch -M main
   git remote add origin https://github.com/<user>/<repo>.git
   git push -u origin main
   ```
2. **Получите лицензионный файл Unity (одноразово, ~2 минуты):**
   - В репозитории → *Actions* → воркфлоу **«Получить файл активации Unity»** → *Run workflow*.
   - Скачайте артефакт **Manual Activation File** (`activation/Unity_v6000.0.23f1.alf`).
   - Откройте https://license.unity3d.com/manual (нужен аккаунт Unity; выполните с доступом,
     если ваш регион блокирует — VPN/другой ПК/телефон) → загрузите `.alf` → скачайте `Unity_v6000.0.23f1.ulf`.
   - В репозитории: *Settings → Secrets and variables → Actions → New repository secret*:
     **Имя `UNITY_LICENSE`**, **значение — содержимое файла `.ulf` целиком** (многострочное).
3. Воркфлоу **«Build WebGL»** запустится автоматически при пуше в `main` (или вручную через
   *Actions → Build WebGL → Run workflow*). Готовый билд — артефакт **WebGL-build** в том же воркфлоу.

### Локальный запуск в Unity (если есть доступ к Unity)

Unity должен быть **6000.0 LTS** с модулем **WebGL**. Откройте проект в Unity — при первом
открытии редактор сам создаст сцену `Assets/Scenes/Main.unity`
(скрипт `Assets/Editor/AutoCreateScene.cs`) — и нажмите **Play**.

> Если что-то пошло не так со сценой: меню **Tools → HowToFish → Пересоздать сцену**.

## Управление

| Клавиша | Действие |
|---|---|
| `WASD` / стрелки | Движение |
| `SPACE` (зажать) | Зарядка заброса удочки; отпустить — бросить |
| `SPACE` (зажать при клёве) | Вываживание (тянуть) |
| `ЛКМ` | Атака текущим оружием (в сторону курсора) |
| `1 / 2 / 3` | Смена оружия: кулаки / нож / пистолет |
| `E` | У лавки: продать рыбу / открыть магазин |
| `F` | Выбросить рыбу из рук |
| `Esc` | Закрыть магазин |

## Геймплей

- **Рыбалка.** Зажмите `SPACE` (шкала заряда), отпустите в сторону воды. Блесна летит в воду,
  ждём клёв. При клёве тяните `SPACE`. Красная метка «ОТПУСТИ!» — момент рывка рыбы:
  в этот момент держать нельзя, иначе леска рвётся.
- **Убийство.** Пойманная рыба вылетает на берег и пытается уползти обратно в воду.
  Бейте кулаками, ножом или стреляйте из пистолета.
- **Killscore.** Множитель цены складывается из бонусов: убийство **в воздухе** (+0.75),
  **с одного удара** (+0.5), **быстро** до 3.5 сек (+0.5). Максимум x3.
- **Продажа.** Погибшая рыба подбирается автоматически. Несите её к торговцу (золотой NPC,
  справа на острове) и продавайте по `E`.
- **Шоп.** Нож ($30) — сильнее кулаков; пистолет ($120) — дальний бой; Удочка 2 ур. ($80) —
  дальше заброс и сильнее вываживание; Аптечка ($20) — +50 HP.
- Рыба царапает при контакте на берегу. При смерти теряете 20% монет.

Виды рыбы: Сардина ($5), Сельдь ($8), Скумбрия ($12), Лосось ($20).

## Сборка WebGL и публикация на Яндекс Игр

1. Запустите воркфлоу **Build WebGL** и скачайте артефакт **WebGL-build** (папка `build/WebGL` —
   содержимое: `index.html`, `Build/`, `TemplateData/`).
   (Локально: *File → Build Profiles → WebGL* → *Build* — результат в `Build/WebGL`.)
2. Упакуйте содержимое папки сборки в **zip** (так, чтобы `index.html` лежал в корне архива).
3. Зайдите в **Консоль разработчика Яндекс Игр**: https://games.yandex.ru/console/
4. Создайте игру → вкладка **Профиль** → заполните название, описание, иконку, скриншоты
   (модерация требует всё заполнить).
5. Загрузите zip → проверьте в **Inspector** (запуск в браузере).

## Интеграция Yandex Games SDK

Публикация на Яндекс Играх **невозможна без подключённого SDK**. В проекте уже есть
слой-заглушка: `Assets/Scripts/Platforms/YandexBridge.cs`. Всё, что он умеет, уже вызывается
скриптами (сейвы, лидерборд, gameplay-тайминг). Осталось «включить» реальный SDK:

1. В Unity откройте **Window → Package Manager → + → Add package by name…**
2. Добавьте официальный плагин Yandex **Plugin Your Games 2.0**.
   Подробная документация: https://yandex.com/dev/games/doc/en/sdk/unity/install
   (стаб-версия проекта рассчитана на то, что вы подключите свой плагин — официальный или
   любой community-вариант, см. раздел ниже).
3. Замените тело методов `YandexBridge` на вызовы выбранного плагина:
   - `Init()` → инициализация SDK / `YaGames.init()`
   - `GameReady()` → `ysdk.features.LoadingAPI.ready()`
   - `GameplayStart/Stop()` → `GameplayAPI.start/stop()` (вызывать перед/после рекламы)
   - `ShowInterstitial(cb)` → `adv.showFullscreenAdv({callbacks})`
   - `ShowRewarded(onReward,onFail)` → `adv.showRewardedVideo({callbacks})`
   - `SaveCloud(json)` / `LoadCloud()` → `player.setData()` / `getData()`
   - `SetLeaderboard(name, score)` → лидерборд
4. Выставьте флаг `IS_SDK_ACTIVE = true` в `YandexBridge.cs`, чтобы включить реальные вызовы.

**Где в игре уже используются стаб-вызовы:**
- `GameBootstrap.Start` → `Init()`, `GameReady()`, `GameplayStart()`
- `GameState.Save()` → `SaveCloud(...)`, `GameState.Load()` → `LoadCloud()`
- Продажа рыбы → `SetLeaderboard("h2f_coins", money)`

> Между «волнами» рыбалки удобно вызывать `ShowInterstitial` (например, при каждом 3-м
> открытии лавки), а `ShowRewarded` — за бонус монет.

**Альтернативные community-плагины** (если официальный не подходит):
- https://github.com/forcepusher/com.bananaparty.yandexgames — UPM-пакет, не трогает настройки проекта
- https://openupm.com/packages/com.playables-studio.yandexgames-sdk/

## Структура проекта

```
Assets/
├─ Editor/AutoCreateScene.cs        — авто-создание сцены при первом открытии
├─ Scenes/Main.unity                — создаётся автоматически (в нём только GameBootstrap)
└─ Scripts/
   ├─ Core/GameBootstrap.cs         — сборка мира из кода + TutorialBrain + CameraFollow
   ├─ Core/GameState.cs             — монеты, инвентарь, сейвы (PlayerPrefs + облако)
   ├─ Core/Palette.cs               — генерация спрайтов (круги/квадраты) без ассетов
   ├─ Core/World.cs                 — все константы мира (границы, вода, берег)
   ├─ Platforms/YandexBridge.cs     — стаб-слой Yandex Games SDK
   ├─ Player/PlayerController.cs    — движение, подбор/перенос рыбы, HP
   ├─ Player/PlayerWeapons.cs       — кулаки/нож/пистолет, наведение и выстрелы
   ├─ Fishing/FishingSpot.cs        — водоём, спавн рыб, поиск цели для клёва
   ├─ Fishing/Fish.cs               — состояния рыбы, Killscore, полёт на берег
   ├─ Fishing/RodController.cs      — зарядка, заброс, вываживание, рывки
   ├─ Combat/KillScore.cs           — расчёт множителя цены
   ├─ Economy/ShopCatalog.cs        — ассортимент лавки
   ├─ Economy/Shopkeeper.cs         — зона лавки + подсказки
   ├─ UI/HUD.cs                     — монеты, HP, шкалы, подсказки, вспышки
   ├─ UI/ShopPanel.cs               — окно лавки (покупка/продажа)
   ├─ UI/FloatingText.cs            — всплывающие тексты и эффекты
   └─ UI/Ui.cs                      — хелперы построения UGUI
```

## Задел на полную версию

Архитектура уже разбита на отдельные системы; легко добавить:
- новые острова (2-3 водоёма/зоны + телепорт на «лодке»),
- боссов (подписка на `RodController.OnEvent` / `Fish.AnyKilled`), ловушка на других NPC,
- кулинарию (множитель x1.5 при поджаривании),
- инвентарь и другие виды рыб (расширить `FishDefs`),
- мобильные виртуальные кнопки для тач-управления (WebGL на телефонах).

## Известные ограничения MVP

- UI построен на legacy UGUI (`Text`/`Image`) — быстро и работает везде, но выдаёт
  warning-устаревания в Unity 6 (не критично).
- Ориентировано на десктоп-браузер (мышь + клавиатура); тач-управление — следующий шаг.
- Вся графика — процедурные примитивы; при желании заменяются на спрайты/анимации.
